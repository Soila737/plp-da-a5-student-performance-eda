# Student Performance EDA

## Project Summary
This project explores student performance data for a County Education Office.
The dataset contains 1,200 students and was generated using seed 55.

## How to Run
1. Install the required libraries:
   pip install -r requirements.txt
2. Generate the dataset:
   python generate_data.py
3. Open and run student_eda.ipynb in Google Colab or Jupyter Notebook.

## Five Key Insights
1. Report the overall average student score from the notebook.
2. Describe the relationship between attendance and average score.
3. Describe the relationship between study hours and average score.
4. Compare average scores between public and private schools.
5. Identify the county with the highest percentage of students at risk.

## Recommendations
1. Support students identified as at risk with targeted learning assistance.
2. Investigate attendance and study habits when planning student support.

## Limitations
The dataset is artificially generated and may not represent actual student performance.
Relationships between variables do not necessarily prove cause and effect.
